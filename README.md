# 🌸 MangNime
Platform streaming Anime dan baca Komik (Manga, Manhwa, Manhua) gratis dengan UI/UX modern.

## 🚀 Fitur Utama
- Nonton Anime sub Indo (Resolusi SD hingga HD).
- Baca Komik dengan fitur tracking chapter.
- History tontonan/bacaan tersimpan otomatis.
- Fitur Bookmark koleksi.
- Komentar dan diskusi (Powered by Supabase).

## 💻 Cara Menjalankan di Local
1. Clone repo ini: `git clone https://github.com/username/mangnime.git`
2. Install dependencies: `npm install`
3. Copy file `.env.example` menjadi `.env.local` dan isi URL & Key Supabase Anda.
4. Jalankan server: `npm run dev`
